Swatch
Install Features FAQ

Edit your colour tokens live, on the page.

Swatch is a dev-only panel for Vite apps. It finds the colour tokens in your CSS, previews every edit on the real app, and writes the result back to the file.

npm install swatch -D

Try it.That panel is Swatch, and it is editing this page. Change --sky, or press Inspect and click the mountain.

Nothing is saved until you press Save.

Edits preview on the page as you type. When you save, Swatch changes that one value in your stylesheet and leaves every other byte alone: comments, spacing and order stay yours. This is the file behind this page; save an edit and watch the line change.

Install

          
Three steps, and no configuration. It only runs in development: a production build never contains it.

          
    
            
  1. 
              
    Add the package
    
              
    As a dev dependency.
    
              
    npm install swatch -D
    
            
    2. 
            
  2. 
              
    Add the plugin
    
              
    One line in your Vite config.
    

    // vite.config.ts
import swatch from "swatch/vite"

export default {
  plugins: [swatch()],
}
    
            
    3. 
            
  3. 
              
    Start your dev server
    
              
    Swatch sits in the bottom-left corner. It has already found your stylesheets and listed their colour tokens, light and dark.
    
              
    npm run dev
    
            
    4. 
          

        


        

          
Features

          
Everything below is in the panel at the top of this page.

          

            
Live preview
Every edit shows on your real app as you type. Reset takes back everything, saved or not.

            
Light and dark, side by side
Each token's two values in one row, read from .dark, [data-theme] or the system preference.

            
Inspect
Hover the page to see the tokens behind any element. Click to filter the list to them; shift-click to add more.

            
Contrast
Each foreground shows its WCAG ratio against its surface, and Inspect checks any text on the page.

            
A real colour picker
With alpha, in HEX, RGB, HSL or OKLCH. Switching format never loses the colour.

            
Token references
Type - in a value to search your tokens and insert var(--name). Aliases show what they resolve to.

            
Uses
How many times each token is used across your project, by file. Zero means it is safe to delete.

            
Works with your agent
A built-in MCP server lets a coding agent read your tokens, commit what you saved, and send colours back for you to preview.

          

        


        

          
FAQ

          

          

            
Does it ship to production?
No. The plugin only applies to Vite's dev server. A production build has no panel, no script and no route from it.

            
How does it find my tokens?
It reads your stylesheets for custom properties declared on :root or html, in Tailwind's @theme, and on your dark selector. It lists the ones whose values are colours, as the browser reads them. You can name the stylesheet yourself with the css option.

            
Will it reformat my CSS?
No. Your stylesheet is parsed, the one declaration is changed, and the file is written back with everything else byte for byte the same. A value that would break the file, like an unclosed bracket, is refused before anything is written.

            
Does it work with Tailwind?
Yes. Tokens in @theme are listed, and utilities like bg-card or text-brand/60 are counted as uses of their token.

            
Do I need React?
No. The panel runs in a shadow root with its own copy of React, so it works the same in React, Vue, Svelte, Solid or plain HTML, and your app's CSS can't restyle it.

            
Which frameworks does it support?
Any app served by Vite. Where the framework renders the HTML itself, such as SvelteKit, Astro or Remix, you add one script tag to your root layout in development. Next.js is not supported yet.

            
What happens if I make a mistake?
There are no mistakes here. Nothing touches your file until you press Save, and Reset puts back everything the tab has saved.

            
How does it work with a coding agent?
Run npx swatch mcp as an MCP server in your agent. From the panel you can then ask it to commit what you saved, or to pull colours from a Figma file. What the agent sends back loads as unsaved edits, so you see every value on the page first.

            
Is it free?
Yes. Swatch is open source under the MIT licence.
